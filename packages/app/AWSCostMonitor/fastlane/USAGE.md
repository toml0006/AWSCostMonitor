# fastlane — App Store Connect ops

These lanes handle the App Store Connect side of releases. **Binaries are built and
uploaded by Xcode Cloud** — fastlane here does not build or upload a binary.
(`README.md` is auto-generated by fastlane; edit this file, not that one.)

## Requirements

- **fastlane ≥ 2.2xx** (modern ASC review-submission API). Install via Homebrew:
  `brew install fastlane` → `/opt/homebrew/bin/fastlane`.
- Heads-up: an old fastlane 2.172 lives at `/usr/local/bin/fastlane`. If `which
  fastlane` shows that, call `/opt/homebrew/bin/fastlane` explicitly or put
  `/opt/homebrew/bin` first on your `PATH`. The old one cannot submit for review
  (uses an API Apple removed).

## Auth

App Store Connect API key. Copy `fastlane/.env.example` → `fastlane/.env` (gitignored)
and set:

- `ASC_KEY_ID` — key id (default `A883B9G6LZ`)
- `ASC_ISSUER_ID` — issuer UUID (ASC → Users and Access → Integrations → App Store Connect API)
- `ASC_KEY_PATH` — path to the `.p8` (default `~/.appstoreconnect/private_keys/AuthKey_<KEY_ID>.p8`)

The `.p8`, `.env`, and generated `asc_api_key.json` are never committed.

## Lanes

```
fastlane mac status                            # version states, attached build, review-submission state
fastlane mac submit version:1.7.0 build:109    # submit an already-uploaded build for review
fastlane mac notes  version:1.7.0              # push release notes / metadata without submitting
fastlane mac pull_metadata                     # download current metadata into fastlane/metadata
```

`submit`/`notes` push the metadata under `fastlane/metadata` (run `pull_metadata`
first to seed it, then edit `en-US.lproj` / `release_notes.txt`).

Verified working: `fastlane mac status` authenticates via the API key and reports
live ASC state (e.g. `1.7.0  WAITING_FOR_REVIEW  build 109`).
